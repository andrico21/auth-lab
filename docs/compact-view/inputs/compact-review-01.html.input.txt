<h3 id="mc-r02-per-step-cryptographic-interpretation-is-deleted">MC-R02
— Per-step cryptographic interpretation is deleted</h3>
<p><strong>Code:</strong> <code>src/compact-view.js:227</code>
(<code>renderData</code>); <code>src/app.js:1438</code>
(<code>stepHtml</code>).</p>
<p>Compact removes every <code>.step-detail</code> node from the shared
action renderer. That class is used for both an ordinary description and
the distinct <strong>Cryptographic interpretation</strong> paragraph.
Consequently Compact retains the heading but deletes its explanation.
The current card’s ordinary detail and the global profile’s crypto
section do not restore the missing per-event text.</p>
<p><strong>Reproduction:</strong> open
<code>lab-smb-multichannel-binding-success</code>, select Cryptographic
detail, inspect a completed source event ending in
<code>:mc-read-response-unwrap</code> (zero-based index 65 / displayed
event 66), then expand Data and checks. The heading is empty. Full at
the same event contains the authored transform, S2C cipher-key
derivation, authenticated READ header and data explanation. The same
omission is confirmed for <code>:mc-read-response</code> and
<code>:mc-read-accept</code> at indices 64 and 66.</p>
<p><strong>Worker correction:</strong> remove only duplicated ordinary
description nodes, or explicitly render the authored crypto paragraph
from the same data. Preserve the existing incomplete-prefix
restrictions; restoring detail must not reveal future payloads or imply
that a check has already succeeded.</p>
<p><strong>Acceptance:</strong> assert the exact authored explanation is
present at its appropriate completed boundary in Compact and Full,
across detail changes and view switches. Cover a per-event override and
the existing profile fallback. Keep separate negative assertions for
intermediate prefixes and unreadable/opaque values. An empty heading or
unrelated profile text cannot satisfy content parity.</p>
<h3 id="mc-r03-history-action-replay-is-labelled-journey">MC-R03 —
History action replay is labelled Journey</h3>
<p><strong>Code:</strong> <code>src/study-controller.js:158</code>;
displayed by <code>src/compact-view.js:156</code>.</p>
<p>Full timeline replay inside a field/exact-object investigation uses
player kind <code>trace-step</code>. <code>studyQueue()</code> does not
classify that kind and falls through to <strong>Journey</strong>.</p>
<p><strong>Reproduction:</strong> start Basic Keycloak in Full; open the
<code>account-password</code> exact history; activate its second Full
timeline row; select Compact. The one-row replay is labelled
<strong>Active scope: Journey</strong>, even though the retained exact
history has three rows, <code>objectTraceSelection</code> remains
<code>account-password</code>, and Return to journey is shown. Source
and emitted reproduce it; canonical state is preserved.</p>
<p><strong>Worker correction:</strong> identify <code>trace-step</code>
explicitly as the selected action within its parent field or
exact-object investigation. Keep the one-row queue, exact elapsed time
and parent trace identity. Do not clear the investigation or replace the
queue merely to make the label true.</p>
<p><strong>Acceptance:</strong> positive labels for exact-object and
field-history timeline replays, including paused switches and queue
overview. Keep ordinary journey, selected journey step, connection
subset and complete history labels distinct. Retain existing
cursor/queue continuity assertions.</p>
