<h3 id="mc-r01-chapter-controls-and-comparison-content-closed">MC-R01 —
Chapter controls and comparison content: closed</h3>
<p>Presentation remounts now invalidate cached chapter and field-index
DOM state. A cache belonging to the old mounted view no longer prevents
the new view from constructing its controls. This does not reset the
canonical study state.</p>
<p>Independent checks exercised <code>lab-dnssec01</code>,
<code>lab-dnssec15</code> and <code>lab-mcp09</code>, starting in both
Full and Compact, through repeated switches at partial playback
positions. They compared exact player/canonical state, retained queue
identity, chapter button identities, enabled/pressed state, and
credential comparison rows. Actual chapter activation updated the
expected source cursor and current chapter in both presentations. MCP
issuer, resource and prefix-dependent held/not-held explanations
remained present and correct.</p>
<p><strong>Closure basis:</strong> positive source and exact
emitted-bundle execution, implementation inspection, and the bound
current native correction evidence. No new DNSSEC or MCP model change
was required.</p>
<h3 id="mc-r02-cryptographic-explanation-body-closed">MC-R02 —
Cryptographic explanation body: closed</h3>
<p>Ordinary descriptive text is now marked separately as
<code>step-description</code>. Compact removes that redundant
description without deleting the authored cryptographic explanation that
shares the broader detail styling.</p>
<p>Independent checks asserted the full event-specific explanation for
three SMB multichannel actions: protected read response, unwrap and
accept. They also exercised the MCP/profile fallback, Journey/Crypto
switching, and repeated Full/Compact transitions. In Compact, before the
corresponding source event completes, future payload and cryptographic
interpretation remain withheld. At the completed prefix, the exact
explanation appears in both presentations.</p>
<p><strong>Closure basis:</strong> actual explanatory body text and
prefix gating were checked; a heading or a nonempty container alone was
not treated as success.</p>
<h3 id="mc-r03-selected-action-replay-scope-closed">MC-R03 —
Selected-action replay scope: closed</h3>
<p>The scope label now recognizes the selected-action queue kinds,
including <code>trace-step</code>. Where an exact-object or field
investigation remains the parent, the label names that parent rather
than incorrectly presenting the one-action queue as the whole
journey.</p>
<p>Independent checks used both actual Full timeline activation and the
Full inspector Replay control, with exact-object, field and parent-free
contexts. They paused replay, switched presentations, compared full
state and queue identity, and verified the one-row Compact queue and
current-action title. Return to journey cleared the investigation
selection, restored the journey scope and retained the reached canonical
source prefix.</p>
<p><strong>Closure basis:</strong> both replay entry points and all
three parent contexts passed. This includes the inspector boundary
addressed in the worker’s later correction, not only the original
timeline example.</p>
<h3 id="mc-r04-field-accessibility-metadata-closed">MC-R04 — Field
accessibility metadata: closed</h3>
<p>Shared field-control metadata now follows the active presentation.
Compact controls point to the inline
<code>compact-field-definition</code> region and no longer advertise a
popup dialog or an unsupported F2 shortcut. Full keeps its implemented
dialog/F2 interface.</p>
<p>Independent checks covered field-index and current-action controls,
their actual explanatory content, view roundtrips, and Full
F2/open/Escape/focus-return behavior. Compact activation focuses the
named definition region at the beginning of the explanation. Reading a
field does not select a protocol action or change the canonical
snapshot.</p>
<p><strong>Closure basis:</strong> corrected semantics and handler
behavior pass. This does not substitute for hearing and understanding
the interface with an actual screen reader.</p>
<h3 id="mc-r05-inventory-help-lifecycle-closed">MC-R05 — Inventory help
lifecycle: closed</h3>
<p>Help opening and closing now render the current help state before
resolving and focusing the surviving control. Escape handles help
dismissal before the outer inventory disclosure. Logical focus recovery
also covers selection rerenders and presentation roundtrips.</p>
<p>Independent checks exercised Close, Escape and trigger dismissal,
retained the open outer holdings disclosure, and verified connected
focus on the appropriate surviving trigger. A rerender and Full/Compact
roundtrip retained usable help. Automatic player rendering did not pull
focus away from Play into an already open help panel.</p>
<p><strong>Closure basis:</strong> state, DOM and focus agree across the
reported lifecycle boundaries. No modal redesign or human
speech/comprehension acceptance is inferred.</p>
<h3 id="mc-r06-search-draft-transfer-closed">MC-R06 — Search-draft
transfer: closed</h3>
<p>The picker now retains one bounded transient nonempty draft across
dismissal toward a view switch and promotes it only when the switch
occurs. Preservation no longer depends on pointerdown alone. Ordinary
reopening, explicit cancellation, committed selection and context
invalidation remain separate transitions. Empty and whitespace-only
visits retain the ordinary closed selected-label behavior.</p>
<p>Independent checks covered both pickers, both starting presentations,
keyboard and pointer transfer sequences, and roundtrips. They retained a
nonfirst active result with the raw query, while comparing lesson/model
identity and full canonical/player state. Escape, toggle, clear,
ordinary reopening, unmatched queries, empty-result Enter,
empty/whitespace visits and changed lesson context did not resurrect or
misapply a draft.</p>
<p><strong>Closure basis:</strong> behavioral parity passed in source
and emitted execution. Harness event sequences are application-level
checks; they are not independently performed browser Tab traversal.</p>
<h3 id="mc-r07-field-reading-and-scope-navigation-closed">MC-R07 — Field
reading and scope navigation: closed</h3>
<p>Compact now begins with current-lesson fields, uses a declared
<strong>40-field batch</strong>, places the selected definition before
the index and keeps explicit global browsing/search available.
Independent initial observations were <strong>35 fields in Basic
Keycloak, 35 in Core and 40 of 48 in MCP09</strong>. Explicit global
browsing retained all <strong>10,843 definitions</strong>, initially
displayed 40, and expanded to 80 without duplicates or loss of the first
batch. Show more focused the first newly exposed field.</p>
<p>Independent source and exact emitted checks found and opened an
actual out-of-lesson definition through global search. Query changes
reset the visible batch. A context change resets batching; an active
global field query can remain until the user explicitly chooses Current
lesson fields, which clears it. This is distinct from the cancelled
scenario-picker draft behavior in MC-R06.</p>
<p>Field activation focuses the explanatory region and reveals it.
Explicit Follow opens a paused field history, focuses/reveals the
current action and exposes Return. Back to definition retains the active
history queue and source prefix. Return restores journey scope without
changing the reached prefix. Real partial-cursor paths and empty
histories were checked in all three lessons. Empty histories do not
start playback. Automatic playback did not repeatedly scroll or steal
focus; explicitly returning to a definition paused playback and
preserved the exact queue and elapsed time.</p>
<p><strong>Closure basis:</strong> 18 independent grouped records passed

worker’s synthetic receipt/verification boundary cases. The supplied
measured field endpoints all meet their declared latency targets,
subject to the open variability conditions in section 6. Physical-phone
ergonomics and human AT remain separate acceptance work.</p>
