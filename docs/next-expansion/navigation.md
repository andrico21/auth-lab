# Next-expansion navigation contract

The plan's scenario/runtime/family mappings are frozen in `scenario-manifest.json`. The grouped navigation is implemented on the accepted WIN-11 lineage. [Implementation scope](implementation.md) and [bounded P0 native evidence](../verification/next-expansion/p0/native-acceptance-04-summary.json) distinguish authored features, the exercised 214-choice foundation and the separate final expanded acceptance.

## Compact beginner surface

- One grouped searchable workspace/family combobox, not a second crowded row of tabs. Current workspace and family remain visible and announced.
- Reuse the existing editable scenario-picker behavior with explicit control/option namespaces. Independent menus must not share option IDs, active descendants or selection. Filtering is not activation; native text editing and composition remain available.
- Keep global scenario search and all deduplicated choices. Workspace/family choice deliberately starts its authored default; related lessons start fresh destination contexts, not a hidden transfer of tickets, tokens, sessions or privilege.
- Present a compact starter surface. More ready-made journeys, source/profile caveats and advanced configuration remain discoverable in accessible expandable details. The first viewport must expose the learning question, key starting identities, Play and useful flow, not several screens of menus.
- Keep Play, Reset and speed above the animation. Put the unchanged step-name, component-internals and held-object toggles in the labeled Map display options group immediately below it, with 44-pixel label targets. Names wrap rather than relying on actor-name ellipses.
- Keep the field pane open by default. Preserve global typed field search, exact selected field/object identity and logical keyboard order; do not claim an optimization by closing or omitting it.
- Core and Web presets retain the complete field catalog; profiled lab lessons initially scope their field list to their journey. Typed search remains global. Keep field search metadata in the row cache rather than duplicate DOM attributes. Ordinary field rendering preserves every button and its explicit accessible name, native Tab/F2 access and touch selection. Rejected CSS deferral trials do not justify virtualizing away fields or changing their order.

## Existing routes and identities

Existing workspace IDs and family route segments remain unchanged. All 214 baseline choice IDs, aliases and canonical hashes remain valid; unsupported hashes retain the existing safe fallback. Files' SMB entry navigates to the existing `#/windows/files/lab-smb-nonjoined-kerberos`, adding no model, alias or counted choice.

New destinations follow the frozen mapping: Files/NFS; six Workstations sign-in/elevation families; Foundations/JWT; five Kubernetes families; MCP/authorization. A workspace becomes selectable only with an actual integrated representative model and held-object builder. No empty placeholder route or silently substituted web lesson.

## Interaction and focus

Typing, clearing or moving the highlighted combobox option does not select a scenario, alter canonical state, pause/reset playback or steal focus. Enter or a deliberate pointer/touch selection activates it. Escape/Tab/outside focus close only the relevant menu; the selected label returns. An active descendant always identifies a present option in that menu.

Selection, route changes, related controls, source/details expansion and nested F2 help preserve or restore logical focus. Rebuilt starters fall back to persistent Play if their initiating control no longer exists. Disconnect removes both picker instances' document/root listeners. Source links name the standard/section and use user-initiated `target="_blank" rel="noopener noreferrer"` navigation.

## Verification boundary

Retain a runnable native action collector with source/HTML/runner/runtime/browser identities. Exercise desktop and 390px layouts, intentional graph scrolling, both folded/expanded logical owners, keyboard, touch, actual browser-menu 200%/400% zoom and nested-help return. CSS viewport simulation is not real zoom. Manual G01 speech/comprehension stays open under `open-gates.json` until a human supplies actual observations.

## Targeted correction collection

`tools/verification/run-next-expansion-native.mjs --phase=review --review-fixtures=/absolute/fixtures.json --expectedHTMLhash=SHA256 --output-new-dir=/absolute/new-directory` runs an explicit bounded correction scope in source HTTP, standalone HTTP and file mode. The fixture file pins the independent review and selects authored worksheet cases, meaningful field/exact-object replay boundaries and touch surfaces. Optional starting-text requirements are checked in the visible starting context, not closed advanced references.

The review phase retains ordinary navigation, composition and the complete field-button accessibility census. Primary Play/Pause/Resume and field/exact replay controls are exercised in both themes, with default/hover/keyboard-focus and actual native-touch retained-hover observations. No controls are virtualized away and no AX result is called speech.

Passing this targeted phase is not the complete final matrix, actual browser-menu zoom, physical-device testing, G01 speech or live-platform acceptance. The existing P0/final phases still require their separate actual 200%/400% browser-menu procedure; the review phase does not weaken those gates.

`--review-contrast-only=file:touch` limits the review phase to one named primary-control contrast context. The same option accepts `source-http` or `built-http` and `desktop` or `touch`. It runs no semantic-case, navigation or geometry matrix and reports that narrower acceptance scope explicitly. Use it to recheck an affected control scope without relabeling an earlier failed report or repeating unrelated protocol cases.

Control capture waits for the current live element to have no pending/running animation before reading computed colors. Playback can cancel a CSS transition, so its stale `Animation.finished` promise is not a reliable paint-settling boundary. Assertions and normal timeouts remain unchanged.
